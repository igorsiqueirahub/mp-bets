# MP das Bets

Página para embed sobre a MP 1.394/2026, que proíbe as apostas de quota fixa no Brasil: resumo da MP, cenário atual, posição do setor (IBJR) e histórico da regulamentação.

- Página: `index.html` (publicada via GitHub Pages em https://igorsiqueirahub.github.io/mp-bets/)
- Código do iframe para a matéria: `embed.html`

O iframe ajusta a altura sozinho por `postMessage` (mensagens com prefixo `mp-bets:`). Dá para abrir direto numa aba com `#resumo`, `#cenario`, `#setor` ou `#historico`.

Situação da tramitação atualizada em 22/10/2026.
